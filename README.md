## IP 这一关：机房 IP、原生 IP、双 ISP 住宅 IP 差在哪

平台风控查的是 IP 类型。普通 VPS 分到的是数据中心 IP，特征太明显：一段 IP 可能被几十上百个账号共享过，亚马逊、TikTok、eBay 的风控系统一查就露馅，结果就是限流、封号，严重的整个店群一起完。

住宅 IP 是从真实宽带运营商申请的家庭宽带 IP，属性上等同于一个普通家庭用户在操作店铺。双 ISP 属性指这个 IP 同时带两个运营商的归属标注，被判定成代理的概率更低。

判断方法很简单，下单前自己查：把 IP 丢进 ipinfo.io 或 scamalytics，看到"Hosting"字样就是机房 IP，不是住宅。

## 下单前值得问清的几件事

**Q：做跨境电商一定要住宅 IP 吗？**
看你做哪个平台。亚马逊和 TikTok 对 IP 类型审查严，机房 IP 被标记的概率明显更高；独立站、低风险品类、账号历史干净的，普通 IP 也能跑。但账号反复被封的，先解决 IP 属性比换配置有用。

**Q：一台机器能挂几个店？**
从 IP 层面说，一个 IPv4 就是一个网络身份，混用多个账号风险很高。要跑 5 个店就准备 5 个独立 IP，配指纹浏览器隔离环境。机器配置本身不用高，1 核 1G 跑浏览器加管理工具够用，同时开多个指纹环境上 2 核 2G 更稳。

先看你的流量结构。JustHost 的基础套餐本来就是 300 Mbps 起、不限流量，日常访问和图片加载不是瓶颈；真正的瓶颈通常在数据库和未压缩的图片。带宽按需加，10 Mbps 一档是 ¥16.80/月，比一上来就买独享 1 Gbps 理智。
